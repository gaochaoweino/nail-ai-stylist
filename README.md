## 🚀 核心功能  
### 1. 美学设计灵感工厂  
- **智能素材采集**  
  - 自动爬取小红书/抖音/Pinterest 美甲热帖（日均 10k+ 条），过滤非可打印内容（如手绘稿）  
  - **风格识别模型**：用 CLIP 微调识别 50+ 细分标签（法式/渐变/浮雕等），精准匹配美甲机工艺限制  
- **模板自动化适配**  
  - 将流行款式转换为设备可用的矢量模板（.svg），自动优化线条复杂度与色块数量  
  - 输出带热度指数的 **动态灵感库**，支持按“流行度/工艺难度/季节”筛选  

### 2. 潮流趋势雷达  
- **热点实时监控**  
  - 追踪 200+ 社交平台热词（如 `#美甲趋势2024`）、KOL 帖子互动增速，预警新风格爆发  
- **爆款预测引擎**  
  - 融合时序数据（搜索量/UGC 增长率）与视觉分析（色彩 Pantone 匹配），输出 **趋势热力图**  
  - 示例输出：  
    > **「琉璃甲」爆发预警**（72h 内抖音搜索 +210%）  
    > ✅ 推荐适配：透明底胶+珠光粉（设备支持度 ★★★★☆）  
    > ⚠️ 风险：需新增 2 种珠光色耗材（供应链响应周期 5 天）  

### 3. 行业决策中枢  
- **统一数据看板**  
  - 整合第三方报告（Euromonitor/QuestMobile）、竞品上新数据、用户评论 NLP 分析  
  - 动态生成 **价格带健康度**、**区域偏好热力图**、**竞品功能拆解表**  
- **策略自动化输出**  
  - 输入问题（如“Q3 主推什么价位？”），自动返回数据结论：  
    > **推荐 128-168 元价格带**（占新客转化 52%，竞品缺口率 31%）  
    > 依据：小红书“平价美甲”声量年增 87%，但竞品 60% 集中于 99 元以下
